1. 문제 설정과 기호

여과 확률공간 $(\Omega,\mathcal F,(\mathcal F_t)_{t\ge0},\mathbb P)$ 위에서 각 개체에 대해 다음을 정의한다. 단일 사건(single event) 설정이다.

기호의미
$T\in\mathbb R^+$진짜 사건(사망·고장) 발생 시점
$C\in\mathbb R^+$우측 중도절단 시점
$\tilde T=\min(T,C)$실제 관측된 종료 시점
$E=\mathbb I[T\le C]$사건 지시자 ($1$=사건 관측, $0$=중도절단)
$\mathcal H_t$시점 $t$까지 불규칙 간격으로 수집된 $d$차원 관측 궤적
$R_t=(T-t)\mid(T>t)$잔여 수명(residual lifetime) — 이 방법의 예측 대상
$F(s\mid\mathcal H_t)$$P(R_t\le s\mid\mathcal H_t)$, 잔여수명 CDF
$S(s\mid\mathcal H_t)$$1-F(s\mid\mathcal H_t)$
$\Delta t_j=t_{j+1}-t_j$방문 사이 실제 경과시간
$\bar\theta$타깃 네트워크 파라미터

비정보적·독립 중도절단 $T\perp C\mid\mathcal H_t$를 가정한다. 목표는 임의 시점 $t$에서 $\mathcal H_t$로부터 완전한 조건부 잔여수명 분포를 추정하는 것이다.

2. 시간적 일관성과 비정수 이동 문제

2.1 시간적 일관성

시점 $t$와 $t+\Delta t$ 사이에 사건이 없었다면($T>t+\Delta t$), 잔여수명은 경과한 만큼 정확히 줄어든다: $R_t=\Delta t+R_{t+\Delta t}$. 분포로 쓰면 두 시점의 예측이 단순한 시간 이동으로 연결된다.

$$F(s\mid\mathcal H_{t+\Delta t})\;\longleftrightarrow\;F(s+\Delta t\mid\mathcal H_t)$$

이 관계를 학습 신호로 삼는 것이 TD의 출발점이다. 다음 관측에서의 예측을 $\Delta t$만큼 옮기면 현재 관측의 target이 된다.

2.2 불규칙 관측이 만드는 문제

방문축 방법(TCSR·DeepTCSR)에서는 이동량이 항상 정수 1 step이다. 따라서 확률벡터를 배열에서 한 칸 미는 것(jnp.roll)으로 이동이 정확히 표현된다.

실제 시간에서는 이 방식이 깨진다

ICU·센서 데이터의 $\Delta t$는 실수다. 격자 간격의 배수가 아닌 이동을 가장 가까운 인덱스로 반올림하면 매 전이마다 최대 $\Delta z/2$의 오차가 생기고, TD가 전이를 따라 재귀하므로 이 오차가 누적 시간 편향으로 쌓인다.

단순히 반올림 정밀도를 높이려고 격자를 촘촘히 하면 $K$가 커져 계산량과 bin당 표본 수 문제가 따라온다.

SurvTD가 푸는 문제

이 방법론의 두 구성요소는 정확히 이 문제에 대응한다.

  • 재생 이동 연산자 $\Phi_{\Delta t}$ (§3) — 시간 경과를 확률질량의 수송으로 정의해 임의의 실수 $\Delta t$에 대해 총 질량을 보존한다.
  • 범주형 투영 $\Pi$ (§4) — 격자에 떨어지지 않는 이동 결과를 반올림 대신 인접 두 격자점에 선형 분배한다.

부수적으로 이 구성은 덧셈만으로 이루어지므로, 조건부 밀도를 재정규화하는 형태($p(s+\Delta t)/S(\Delta t)$)에서 나타나는 작은 분모 문제를 애초에 만들지 않는다. 단 이는 표현 방식의 성질이며, 선행연구가 그런 나눗셈을 사용한다는 뜻은 아니다 — TCSR와 DeepTCSR는 hazard 공간에서 생존확률을 곱하는 가중 BCE를 쓴다.

3. 재생 이동 연산자 $\Phi_{\Delta t}$

3.1 확률 질량 수송으로의 재정의

생존을 유지하는 동안 잔여수명 확률변수는 결정론적 드리프트 $\dfrac{dR_t}{dt}=-1$을 겪는다. 따라서 $\Delta t$가 경과하면 잔여수명 축 위의 질량은 좌측으로 $\Delta t$만큼 평행이동한다. 구간 $[0,\Delta t)$에 있던 질량은 그 사이 이미 사건이 경과했다는 뜻이므로 $s=0$의 흡수 경계(absorbing boundary)로 완전히 이관된다.

3.2 정의

$$\boxed{\;(\Phi_{\Delta t}\,p)(s)=p(s+\Delta t)+\delta_0(s)\int_0^{\Delta t}p(u)\,du,\qquad \forall s\ge0\;}$$

$\delta_0$는 $s=0$의 디락 델타다.

보조정리 1 — 단위 확률질량 보존

$$\int_0^\infty(\Phi_{\Delta t}p)(s)\,ds =\int_{\Delta t}^\infty p(u)du+\int_0^{\Delta t}p(u)du=1$$

임의의 실수 $\Delta t\ge0$에 대해 성립한다는 점이 핵심이다 — 격자 간격의 정수 배수로 제한되지 않는다. 또한 덧셈만으로 이루어진 선형 연산이라 재정규화 항이 등장하지 않는다.

3.3 CDF에서의 작용

$$F_{\Phi_{\Delta t}}(x)=\int_0^x(\Phi_{\Delta t}p)(u)\,du=\int_0^{x+\Delta t}p(u)\,du=F(x+\Delta t)$$

밀도에서는 디락 델타를 다뤄야 하지만 CDF에서는 단순한 인자 이동이 된다. 흡수 경계 처리가 자동으로 들어간다.

4. 범주형 투영 $\Pi$

구현을 위해 잔여수명 최대 지평 $S_{\max}$를 $K$개의 지지 원자 $\mathcal Z=\{z_1,\dots,z_K\}$ ($0=z_1<\dots

$\Delta t$ 경과 후 각 원자는 연속 좌표 $\hat z_k=\max(0,\,z_k-\Delta t)$로 이동하는데, 이 값은 일반적으로 격자에 떨어지지 않는다. 분포형 RL의 표준 투영 기법을 확장해 이동된 질량을 인접 두 격자점에 거리 역수 비례로 선형 분배한다.

$$(\Pi\,\Phi_{\Delta t}\,\mathbf p)_i=\sum_{k=1}^{K}p_k\cdot \left[1-\frac{|\hat z_k-z_i|}{\Delta z}\right]^{+}\cdot \mathbb I\bigl(\hat z_k\in[z_{i-1},z_{i+1}]\bigr)$$

$\Pi$가 §2의 문제를 해결하는 지점

반올림($\hat z_k$를 가장 가까운 격자점으로) 대신 인접 두 점에 선형 분배하므로 개별 이동의 편향이 상쇄되고 총 질량 $\sum_k p_k\equiv1$이 유지된다. $\Delta t$가 격자 간격의 배수가 아니어도 정확하다.

합성 연산자를 $\mathcal T_{\Delta t}=\Pi\,\Phi_{\Delta t}$로 쓴다. $\Pi$는 Cramér 거리에 대해 비확장 사상이며, 이 설계는 $\mathcal T$가 Cramér 거리에서 수축이 되도록 의도되었다. (수렴 분석은 이 문서의 범위 밖이다.)

5. 분포 표현 (head)

5.1 초안 — 범주형 softmax

백본 $f_\theta$가 $\mathcal H_t$를 받아 $K$차원 로짓을 출력하고, softmax로 지지점 위의 확률질량 벡터를 만든다.

$$\mathbf p_\theta(t)=[p_{\theta,1}(t),\dots,p_{\theta,K}(t)]^\top\in\Delta^{K-1}$$

5.2 v2 개정 — 가산 누적위험 파라미터화

research/toy-gradient/method_specification_survtd_v2.md에서는 곱셈 연쇄 $S_m=\prod_{k\le m}(1-h_k)$ 대신 각 로짓이 독립적인 국소 누적위험 증분을 지정하도록 바꾼다.

$$\Delta\Lambda_\theta(s_k\mid h_j)=\operatorname{softplus}(z_{j,k})\ge0,\qquad \Lambda_\theta(s_k)=\sum_{l\le k}\operatorname{softplus}(z_{j,l})$$ $$S_\theta(s_k\mid h_j)=\exp(-\Lambda_\theta(s_k))=\prod_{l\le k}\bigl(1-\sigma(z_{j,l})\bigr)$$

분리된 그래디언트 불변량:

$$\frac{\partial\log S_\theta(s_m)}{\partial z_{j,k}}= \begin{cases}-\sigma(z_{j,k}),&k\le m\\ 0,&k>m\end{cases}$$

즉 $\partial\log S(s_m)/\partial z_k$가 $l\ne k$인 $z_l$에 의존하지 않아 Hessian이 대각이 된다. bin 사이의 곱셈 연쇄가 일으키던 교차 seed 분산 폭발을 제거하려는 설계다.

6. 손실함수

온라인 네트워크 $\theta$와 지연 갱신되는 타깃 네트워크 $\bar\theta$를 운용한다. 타깃은 EMA 계수 $\tau\ll1$로 매 스텝 갱신한다: $\bar\theta\leftarrow(1-\tau)\bar\theta+\tau\theta$.

전체 손실은 Cramér 재생 TD 손실과 경계 지도 손실의 결합이다.

$$\boxed{\;\mathcal L(\theta)=\frac1{|\mathcal B|}\sum_{i\in\mathcal B} \left[\sum_{j=1}^{L_i-1} d_{\text{Cramér}}^2\Bigl(\mathbf p_\theta(t_{i,j}),\; \operatorname{sg}\bigl[\Pi\,\Phi_{\Delta t_{i,j}}\,\mathbf p_{\bar\theta}(t_{i,j+1})\bigr]\Bigr) +\lambda_{\text{term}}\,\mathcal L_{\text{term}}\bigl(\mathbf p_\theta(t_{i,L_i}),\tilde T_i,E_i\bigr)\right]\;}$$ $$d_{\text{Cramér}}(F,G)=\left(\int_0^\infty|F(x)-G(x)|^2dx\right)^{1/2}$$

두 항의 역할

항대상역할
Cramér TD 손실중간 전이 $j=1,\dots,L_i-1$ 시간적 일관성 강제. 다음 방문의 예측을 $\Pi\Phi$로 옮겨 현재의 target으로 삼는다
$\mathcal L_{\text{term}}$마지막 관측 $j=L_i$ 경계 지도. 분포를 실제 관측 결과에 고정(anchor)한다

TD 항만으로는 분포가 자기참조로 표류할 수 있으므로 경계 항이 필수다. $\lambda_{\text{term}}$이 두 항의 균형을 정한다.

적분 범위는 지지 구간 $[0,S_{\max}]$이며, 이산 격자 위에서는 유한합으로 정확히 계산된다. 즉 몬테카를로 적분이 필요 없다.

7. 검열 처리

7.1 초안

$\mathcal L_{\text{term}}$은 사건이 발생한 경우($E_i=1$) 잔여수명 $0$ 지점 $z_1=0$에 전체 질량을 할당하는 교차엔트로피이고, 중도절단된 경우($E_i=0$) 누적 생존질량이 유지되도록 유도한다.

7.2 v2 개정 — SCCT (Survival-Conditional Continuation Target)

Round 1의 실패 모드

$S\le10^{-6}$일 때 흡수 좌표 $\perp$에 질량을 쏟아붓는 처리를 했더니, 네트워크가 검열 환자를 불멸($T=\infty$)로 학습했다.

v2의 결론: $\perp$에 인위적 질량을 절대 주지 않는다

  1. 중간 전이 ($j — 방문 $j+1$에서 살아 있음이 관측되었으므로 그 구간은 정의상 생존 전이다. Bellman 갱신 $R_j=\Delta t_j+R_{j+1}$이 비검열 동역학 위에서 작동한다.
  2. 종료 검열 관측 ($j=L-1,\ E=0$) — 얻는 정보는 오직 $R_{L-1}>r^c_{L-1}$뿐이다. 임의의 종료 디락을 합성하거나 $\perp$에 질량을 버리는 대신 정확한 생존 우도로 지도한다.
$$\mathcal L^{\text{cens}}_{\text{term}}(\theta)=-\log S_\theta\bigl(r^c_{L-1}\mid h_{L-1}\bigr) =\Lambda_\theta\bigl(r^c_{L-1}\mid h_{L-1}\bigr)$$

가산 누적위험 파라미터화(§5.2) 덕분에 이 항이 로짓의 단순한 합이 되어 수치적으로 안정적이다. IPCW 가중치를 쓰지 않으므로 IPCW 분산 폭발과 클램핑 편향이 없다.

8. 알고리즘

# SurvTD — 격자 위 질량 이동 + 삼각 투영
init online θ;  target θ̄ ← θ
support Z = [0, Δz, 2Δz, ..., S_max]          # K 개 원자

for batch in loader:
    total = 0
    for j in range(L-1):                      # 중간 전이
        p_now  = softmax(f_θ(h_j))                      # B x K
        with no_grad():
            p_next = softmax(f_θ̄(h_{j+1}))
            z_hat  = maximum(0, Z - Δt_j)               # 실수 이동 (반올림 금지)
            p_tgt  = triangular_project(p_next, z_hat, Z)   # Π Φ
        total += cramer_sq(cdf(p_now), cdf(p_tgt))      # ∫|F-G|² dx

    # 경계 항
    if E == 1:                                       # 사건 관측
        total += λ_term * cross_entropy(p_θ(h_L), atom=z_1=0)
    else:                                            # 검열 (v2: SCCT)
        total += λ_term * Λ_θ(r_c | h_L)                # = -log S_θ(r_c)

    update_online(total)
    θ̄ ← (1-τ)·θ̄ + τ·θ                                  # EMA
