1. 한 문장 요약과 직관

핵심 아이디어

현재까지의 기록으로 사건까지 남은 시간의 분포를 예측하고, 다음 관측에서의 예측분포를 실제 경과시간만큼 이동시켜 현재 모델의 학습 target으로 사용한다.

오전 9시에 상태를 관측하고 오후 1시에 다음 상태를 관측했으며 그때까지 환자가 살아 있다면, 오후 1시 상태에서의 "앞으로 8시간 이내 사망" 예측은 오전 9시 상태에서의 "앞으로 12시간 이내 사망"을 학습하는 target이 된다. 이미 지나간 4시간을 더하기 때문이다.

이것은 한 샘플의 target이다. 오전 9시의 실제 사망확률이 4시간 동안 0이라는 주장이 아니다. 비슷한 초기 상태에서 일찍 사망한 환자들의 전이도 함께 학습해야 조건부 위험이 추정된다.

2. 문제 설정과 기호

관측 기록은 $(t_0,x_0),(t_1,x_1),\dots$이고, 상태는 인코더로 요약한다.

$$s_n=\operatorname{Encoder}(\mathcal H_{t_n})$$

현재 관측시각 기준으로 첫 종료 사건까지 남은 시간을 $Z$, 사건 종류를 $J$라 한다. 모델이 출력하는 것은 사건별 누적발생확률(CIF)이다.

$$F_c(\tau\mid s)=P\bigl(Z\le\tau,\;J=c\;\big|\;s,\ \text{현재까지 종료 사건 없음}\bigr), \qquad S(\tau\mid s)=1-\sum_c F_c(\tau\mid s)$$
기호의미
$s_n$현재까지의 기록을 요약한 상태 표현
$D_n$전이시간 — 다음 관측 또는 종료 사건까지의 실제 시간
$\tau$예측시간 — 지금부터 몇 시간 뒤를 예측하는지
$H$Horizon — 손실을 평가하는 미래 범위 (사건 시간의 최댓값이 아님)
$c$사건 종류. 첫 임상 목표는 사망 / 생존퇴실 두 종류
$\bar\theta$target 모델 파라미터

예측 대상을 먼저 고정한다

첫 임상 구현의 대상은 현재 ICU 입원 중 사망이다. 종료 사건은 사망과 생존퇴실 두 종류다. ICU 퇴실 이후의 사망은 별도 문제이며 이 설계와 혼합하지 않는다. 데이터 수집 종료처럼 결과가 확인되지 않은 경우는 행정적 검열로 둔다.

$\tau$와 $D_n$을 혼동하지 말 것

$D_n$은 데이터에 기록된 두 관측 사이의 실제 간격이다. $\tau$는 모델에게 묻는 예측 시점이다. 둘 다 실수이며 독립적으로 움직인다.

3. Semi-Markov 세팅

다음 EHR 관측, 사망, 생존퇴실 중 먼저 발생하는 시점까지를 하나의 전이로 정의한다. 사망·퇴실은 별도의 absorbing state로 표시하고, 행정적 검열은 임상 전이가 아니라 관측이 중단된 것으로 처리한다.

3.1 Markov renewal 가정

$$\boxed{\;P\bigl(s_{n+1}\in B,\ D_n\le u\;\big|\;\mathcal H_{t_n}\bigr)=Q(B,u\mid s_n)\;}$$

말로 풀면

현재 상태 표현을 알면 다음 상태와 거기까지 걸리는 시간의 결합분포를 예측하는 데 충분하다.

  • 다음 상태와 경과시간은 독립일 필요가 없다.
  • 경과시간을 지수분포로 제한하지 않는다 — Markov가 아니라 semi-Markov인 이유.

관측시점의 상태·시간 쌍이 Markov renewal 구조를 이룬다.

3.2 명시적으로 하지 않는 주장

  • 이 모델은 관측 상태 사이의 시간을 쓴다. 환자의 몸이 다음 관측까지 변하지 않는다고 가정하지 않으며, 잠재 임상 상태 진입 시각을 추정한다고 주장하지 않는다.
  • 불규칙 관측 자체가 semi-Markov의 증거는 아니다. 위 구조는 명시적인 모델링 가정이다.
  • RNN·Transformer를 써도 상태의 충분성이 자동 보장되지 않는다.

3.3 Model-free

결합분포 $Q$를 직접 추정하는 전이모델은 만들지 않는다. 관측한 삼중항 $(s_n,D_n,s_{n+1})$로부터 사건시간 분포를 바로 학습한다.

4. 분포 표현 (head)

4.1 사양 — 사건별 Weibull mixture

임의의 실수 $\tau$에서 CIF를 닫힌 형태로 평가할 수 있어야 한다.

$$F_c(\tau\mid s)=\pi_c(s)\sum_{m=1}^{M}w_{cm}(s) \left[1-\exp\left\{-\Bigl(\frac{\tau}{a_{cm}(s)}\Bigr)^{b_{cm}(s)}\right\}\right]$$

$\pi_c$와 $w_{cm}$은 softmax, scale $a_{cm}$·shape $b_{cm}$은 양수로 제한한다. 이 형태는 CIF의 단조성과 $\sum_c F_c\le1$을 자동으로 보장한다. 단일 사건이면 $\pi=1$.

왜 연속 head인가

이동이 $\tau-D_n$을 그냥 대입하는 것으로 끝나므로 격자 보간 오차가 없다. 격자 표현을 쓰면 별도의 투영이 필요하다.

Mixture head는 실용적 시작점이며 핵심 신규 기여가 아니다. 장기 tail과 사건 종류 확률은 검열이 많으면 약하게 식별될 수 있다.

구현 우리가 실제로 쓴 head

본 프로젝트에서는 TCSR·DeepTCSR와 head 계열을 정확히 맞추기 위해 Weibull mixture 대신 원본과 동일한 이산 logistic hazard를 실제시간 bin 위에 올렸다.

$$h_\theta(k\mid x)=\operatorname{sigmoid}(\alpha_k+\beta^\top x),\qquad F_\theta(\tau_k\mid x)=1-\prod_{j\le k}\bigl(1-h_\theta(j\mid x)\bigr)$$
  • 격자: grid = linspace(0, H, K+1), $K=32$ (설정 A 재현 시에는 $K=$ 방문 horizon)
  • 비정수 이동은 CDF 선형보간으로 처리 (§5.4)
  • 단일 사건만 사용 (사망). 경쟁위험은 미구현

이 선택의 이유: 세 방법(TCSR / DeepTCSR / SM-TCSR)이 동일한 선형 head를 공유해야 "학습법 효과"와 "시간 처리 효과"를 분리할 수 있기 때문이다. $\tau_k$가 방문 index가 아니라 실제시간 bin이라는 점만 다르다.

5. TD target

각 전이는 무엇이 관측되었느냐에 따라 세 가지로 나뉜다.

5.1 다음 관측에서 생존이 확인된 경우

$$\widetilde F_{n,c}(\tau)= \begin{cases} 0, & 0\le\tau연속 head에서 $F_c(0)=0$이므로 $\tau=D_n$ 경계에서 연속으로 이어진다.

5.2 종료 사건이 관측된 경우

$$\widetilde F_{n,c}(\tau)=\mathbf 1\{c=c^*\}\,\mathbf 1\{\tau\ge D_n\}$$

여기서는 bootstrap을 하지 않는다. 관측된 사실이 그대로 target이다.

5.3 target이 왜 올바른가

모든 가능한 관측·종료 전이를 포함하고 현재 상태가 충분하다는 가정 아래, 참 모델은 다음 조건부 기대값 관계를 만족한다.

$$F_c^{*}(\tau\mid s)=\mathbb E\bigl[\widetilde F_{n,c}^{*}(\tau)\;\big|\;s_n=s\bigr]$$

하나의 다음 상태가 모든 미래를 대표한다는 뜻이 아니다. 여러 환자와 전이에서 얻은 target의 조건부 평균을 학습한다. 검열로 선택된 전이 분포가 이 기대값을 보존하는지는 별도의 검토 대상이다.

5.4 이동의 구현

$D_n$을 반올림하면 안 된다

방문축 방법은 이동량이 정수 1 step이라 배열을 한 칸 미는 것으로 충분했다. 실제 $D_n$은 실수이므로 반올림하면 누적 시간 편향이 생긴다.

  • 연속 head: $\tau-D_n$을 직접 대입 — 보간 오차 없음
  • 격자 head: CDF를 격자 위에서 선형보간해 평가. CDF는 $\tau$의 단조함수이므로 보간해도 유효한 분포로 남는다 (이산 hazard는 bin마다 조건부 사건이 달라 보간이 정의되지 않는다)

구현 우리 코드의 이동

def _shift_cdf(F, grid, D):
    q = grid[None,:] - D[:,None]
    return vmap(lambda f,qq: interp(qq, grid, f, left=0.0, right=f[-1]))(F, q)

left=0.0이 $\tauright=f[-1]이 $H$ 밖을 $F(H)$로 clamp해 꼬리질량 $1-F(H)$를 보존한다. $D_n\ge0$이므로 $\tau-D_n\le H$가 항상 성립해 외삽이 필요 없다.

6. 손실함수

관측 완료 전이에 대해 하나의 분포형 TD 손실을 기본 목적함수로 둔다.

$$\boxed{\;\mathcal L_{\mathrm{TD}}=\mathbb E_n\left[\sum_c\frac1H\int_0^H \Bigl(F_{\theta,c}(\tau\mid s_n)-\operatorname{sg}\bigl[\widetilde F_{n,c}(\tau)\bigr]\Bigr)^2 d\tau\right]\;}$$

$\operatorname{sg}[\cdot]$는 target 쪽 gradient를 차단한다. 단일 사건의 전체 시간축에서는 제곱 Cramér 거리의 형태이며, 여기서는 유한 horizon과 competing-risk CIF에 적용한 제곱오차다.

별도 survival likelihood를 상시 결합하지 않는다

첫 구현의 중심은 이 하나의 TD loss다. 검열 likelihood 같은 보조항은 선택 사항이며, 사용한 버전은 단일 TD loss 버전과 구분해서 보고한다. (Method A는 TD 항 + 경계 지도 항의 2항 구조라는 점이 다르다.)

6.1 왜 CDF 제곱오차인가

이유설명
불편 표본 그래디언트 Wasserstein은 minibatch 표본 그래디언트가 편향된다. Cramér 계열은 불편하다.
시간 거리를 반영 scale sensitive of order 1이라 시간축에서 어긋난 거리에 비례해 벌점을 준다.
직접 계산 가능 모델이 CIF를 직접 출력하므로 KDE나 normalizing flow가 필요 없다.
사건 전이에서 CRPS 종료 사건 target이 계단함수이므로 그 구간의 손실은 정확히 CRPS가 된다.

6.2 수치적분

적분은 평가점을 샘플링해 근사한다.

$$\widehat{\mathcal L}_{\mathrm{TD}}=\frac1{BM}\sum_{n=1}^{B}\sum_{m=1}^{M}\sum_c \Bigl(F_{\theta,c}(\tau_m\mid s_n)-\operatorname{sg}\bigl[\widetilde F_{n,c}(\tau_m)\bigr]\Bigr)^2, \qquad\tau_m\sim\mathrm{Uniform}(0,H)$$

$B$=배치 크기, $M$=적분 평가점 수. 이 평가점은 모델의 출력 bin이 아니다. 격자와 무관하게 뽑는다.

구현 우리 코드의 손실

def loss_fn(params, s_cur, y, mask):
    F = _cdf_from_logits(forward(params, s_cur))
    return sum(((F - y) ** 2) * mask) / (s_cur.shape[0] * (K + 1))

MC 샘플링 대신 고정 격자 위 균등 합을 썼다 ($K+1$개 점). 이는 $\tau_m$을 격자에 고정한 특수한 경우이고, mask가 검열 구간을 제외한다. 단일 사건이라 $\sum_c$는 없다.

7. Horizon — 두 가지 설정

Cramér 거리를 원래 정의대로 쓰면 $\int_0^\infty$가 맞다. 그런데 사망하지 않을 수도 있다는 점 때문에 무한대 적분이 발산할 수 있다.

7.1 왜 발산하는가

"현재 ICU 입원 중 사망"에서는 생존퇴실한 환자가 그 사건을 끝내 겪지 않는다.

$$T_D=\begin{cases}\text{사망까지의 시간},&\text{ICU 내 사망},\\ \infty,&\text{생존퇴실},\end{cases} \qquad \lim_{\tau\to\infty}F_D(\tau)=P(\text{ICU 내 사망})=\pi_D$$

즉 CIF의 극한은 1일 필요가 없다. 생존퇴실 확률이 80%면 사망 CIF는 최종적으로 0.2에 도달한다. 이것은 검열된 환자를 "사망하지 않는 환자"로 분류한다는 뜻이 아니다 — 검열에서는 이후 사건 여부를 모른다.

예측과 target의 극한이 조금만 달라도:

$$F_{\theta,D}(\infty)=0.2,\quad\widetilde F_D(\infty)=0.3 \;\Longrightarrow\; \bigl(F_{\theta,D}(\tau)-\widetilde F_D(\tau)\bigr)^2\longrightarrow0.01$$ $$\boxed{\;\int_0^\infty\bigl(F_{\theta,D}(\tau)-\widetilde F_D(\tau)\bigr)^2d\tau=\infty\;}$$

사망 확률 자체가 조금만 달라도 loss가 무한대가 된다

실제 사망 전이의 target은 극한이 1이고 퇴실 전이의 사망 target은 극한이 0이므로, 사건별 CIF를 무한대까지 단순 적분하는 설계에서는 이 문제가 특히 직접적으로 나타난다.

수치 확인: $F=0.2(1-e^{-0.5\tau})$, $G=0.3(1-e^{-0.5\tau})$에 대해 적분 상한 200 → $d^2=1.97$, 상한 2000 → $d^2=19.97$. 상한에 정확히 비례해 커진다.

$H$까지만 적분한다고 "$H$ 안에 반드시 사망한다"는 뜻이 아니다

$F_\theta(H)=1$이라는 조건을 두지 않는다. $F_\theta(72)=0.3$이어도 전혀 문제없고, 남은 70%는 72시간 이후 사망하거나 끝내 그 사건을 겪지 않을 가능성이다. $H$는 사망시간의 최댓값이 아니라 손실의 평가 범위다.

7.2 설정 (A) — 유한 horizon

$$\mathcal L_H=\mathbb E_n\left[\sum_c\frac1H\int_0^H \bigl(F_{\theta,c}(\tau\mid s_n)-\operatorname{sg}[\widetilde F_{n,c}(\tau)]\bigr)^2d\tau\right]$$
항목내용
적합한 목적6·24·72시간 등 정해진 범위의 예측
구현$\tau_m\sim\mathrm{Uniform}(0,H)$로 $M$개 뽑아 제곱오차 평균
$1/H$horizon 길이 정규화. $H$를 바꿔도 손실 스케일이 유지된다
한계$H$ 이후 tail의 정확성은 이 손실만으로 보장되지 않는다

7.3 설정 (B) — 적분 가능한 가중치를 쓰는 무한 구간

고정 cutoff 없이 모든 미래를 학습하려면, 상한을 $\infty$로 바꾸는 대신 적분 가능한 가중치를 넣는다.

$$\boxed{\;\mathcal L_w=\mathbb E_n\left[\sum_c\int_0^\infty w(\tau) \bigl(F_{\theta,c}(\tau\mid s_n)-\operatorname{sg}[\widetilde F_{n,c}(\tau)]\bigr)^2d\tau\right]\;}$$ $$w(\tau)>0,\qquad\int_0^\infty w(\tau)d\tau=1,\qquad\text{예: }w(\tau)=\rho e^{-\rho\tau}$$
항목내용
적합한 목적고정 cutoff 없이 모든 유한한 미래 시간을 비교
구현$\tau_m\sim w$로 뽑아 제곱오차 평균 — 코드 차이는 샘플러 하나뿐
효과CIF 극한이 달라도 발산하지 않는다. 가까운 미래에 더 큰 비중
한계원래의 무가중 Cramér 거리와는 다른 목적함수다. 아주 먼 미래의 오차에는 상대적으로 약한 신호를 준다

$\rho$는 RL의 reward discount가 아니다

이 가중치는 어느 예측시간을 중요하게 평가하느냐를 정할 뿐이다. TD target은 여전히 $D_n+Z'$이며, 보상을 할인하는 것과는 다르다.

두 설정의 관계

(A)는 $w(\tau)=\frac1H\mathbf 1\{\tau\le H\}$인 (B)의 특수한 경우다. 유한 horizon은 균등 가중, 무한 구간은 감쇠 가중일 뿐 구조가 같고, 구현에서는 샘플러만 교체하면 나머지 파이프라인은 그대로다.

피해야 할 것: 단순히 적분 상한만 $\infty$로 바꾸는 것.

구현 우리가 쓴 설정

설정 (A) 유한 horizon만 구현했다. $H$ = train subset의 사건/검열 시각 0.9 분위수, 격자 $K=32$. 설정 (B)는 미구현이다.

8. 검열 처리

원칙 — 관측된 전이는 쓰고, 없는 것은 만들지 않는다

데이터 상황처리
다음 EHR 상태를 관측했고 이후 추적 종료해당 완료 전이를 TD에 사용
사망 시각을 관측사망 hard target 사용
생존퇴실 시각을 관측퇴실 hard target 사용
마지막 EHR 이후 생존만 추가 확인되고 검열이전 전이는 사용, 추가 구간은 부분 관측으로 별도 보존
다음 상태도 종료 사건도 모름그 미완료 전이의 전체 TD target을 만들지 않음

기록이 $x_0\to x_1\to x_2$에서 끝나고 $x_2$가 살아 있는 마지막 상태라면, $(x_0,x_1)$과 $(x_1,x_2)$를 사용한다. $x_2$를 사망으로 바꾸거나 관측되지 않은 $x_3$를 만들지 않는다. 마지막 도착 상태 $x_2$의 예측은 이전 상태의 bootstrap target으로 쓴다.

검열 이후를 아는 것과, 마지막 상태에서 예측하는 것은 다르다

후자는 사용할 수 있다. 따라서 검열된 환자를 전부 제거하거나 검열 환자의 마지막 관측으로 들어오는 전이를 제외하지 않는다. 다만 그 예측은 공유 파라미터와 다른 환자의 전이에서 정보를 얻는 것이므로, 데이터가 없는 영역의 정확성을 보장할 수는 없다.

검열을 "처리"하는 것과 "편향을 해결"하는 것은 다르다

행정적 종료 전에 완료된 전이만 모으면 긴 전이가 덜 관측될 수 있다. 검열이 외부에서 발생하더라도 완료된 가변길이 전이의 표본분포가 원래 결합분포와 같다고 단정할 수 없다. 이는 별도 검토 대상이며, 원래 TCSR의 생존 가중치는 IPCW가 아니므로 그대로 복사하는 것만으로 해결되지 않는다.

구현 우리 코드의 검열

세 분기를 명시적으로 나눴다: KIND_DEATH / KIND_SURVIVE / KIND_CENSOR. 검열 전이는 $\taumask=0으로 손실에서 제외한다. 부분관측 구간을 위한 보조 likelihood는 쓰지 않았다.

9. 알고리즘

9.1 절차

  1. 분할 — 환자 단위 train/validation/test. 같은 환자의 episode가 split을 넘지 않게 한다.
  2. 전이 구성 — 관측 완료 전이와 미완료 검열 구간을 별도로 만든다. 검열 환자도 완료 전이는 남긴다.
  3. 초기화 — online 모델을 초기화하고 target 모델에 복사한다.
  4. 샘플링 — 환자와 그 환자의 관측시점을 뽑는다. 빈번히 측정된 환자가 과도하게 지배하지 않도록 샘플링 목표를 고정한다.
  5. target 생성 — target 모델로 다음 상태 CIF를 계산하고, 실제 경과시간 이동 또는 관측된 종료 사건으로 target을 만든다.
  6. 업데이트 — 하나의 TD 제곱오차로 online 모델을 갱신. target에는 gradient를 보내지 않는다.
  7. target 갱신 — EMA 또는 주기적 복사. validation 예측 지표로 모델 선택.

9.2 의사코드

# tau 샘플러만 바꾸면 유한 horizon <-> 가중 무한 구간이 전환된다.
for batch in loader:
    tau  = sample_times(mode)          # (A) Uniform(0,H) | (B) w(tau)=rho*exp(-rho*tau)
    pred = online.cif(batch.history_prefix, tau)         # B x M x C

    with no_grad():                                      # stop-gradient
        target_cif = zeros_like(pred)

        # ① 생존 확인 -> 실수 D 만큼 이동해 bootstrap
        alive       = batch.transition_kind == "observation"
        shifted_tau = clamp(tau - batch.delta_hours, min=0)
        target_cif[alive] = target.cif(batch.next_history_prefix[alive],
                                       shifted_tau[alive])

        # ② 종료 사건 -> 계단함수 hard target
        ended = ~alive                 # loader 에는 완료된 임상 전이만 포함
        target_cif[ended] = event_indicator(tau, batch.delta_hours[ended],
                                            batch.event_cause[ended])

    loss = ((pred - target_cif) ** 2).sum(dim="cause").mean()
    update_online(loss)
    update_target_by_ema()

실제 구현에서는 시간 tensor broadcasting, 종료 행 인덱싱, $F_c(0)=0$, target 인코더의 gradient 차단을 명시적으로 확인한다. 추론 시에는 현재까지의 기록과 online 모델만 필요하다.

9.4 인코더

첫 모델은 causal GRU. 입력은 측정값, mask, 변수별 마지막 측정 이후 시간, 입실 후 경과시간, 정적 특성이다. 미래 측정으로 보간하거나 전체 이력을 미리 요약하지 않는다. 정규화 통계는 train split에서만 계산한다. target 모델은 자신의 인코더로 다음 이력을 처리한다.
